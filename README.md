# 🚀 ProductIQ – AI-Powered Product Intelligence Platform

Transform raw industrial product datasheets into structured, validated, and commerce-ready intelligence using AI, OCR, RAG, and Knowledge Graph validation.

---

## 📌 Problem Statement

Industrial product catalogs are usually available as PDFs, scanned documents, or technical datasheets. Extracting structured product specifications manually is slow, inconsistent, and difficult to validate against engineering standards.

ProductIQ automates this entire workflow using AI, enabling faster catalog digitization, intelligent search, and reliable product validation.

---

# ✨ Key Features

- 📄 Upload Industrial Product Datasheets (PDF/Image/Text)
- 🤖 AI-powered Product Information Extraction
- 🔍 OCR-based Document Processing
- 📚 RAG (Retrieval Augmented Generation)
- 🧠 Knowledge Graph Validation
- ⚡ Google Gemini AI Integration
- 📊 Interactive Dashboard
- 🔎 Intelligent Product Search

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/iamsonam08/ProductIQ.git
```

Move into project

```bash
cd ProductIQ
```

Install dependencies

```bash
npm install
```

Create environment file

```bash
cp .env.example .env
```

Run locally

```bash
npm run dev
```
